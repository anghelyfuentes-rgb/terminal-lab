# Semana 01 - Git y GitHub

## Qué hace

Crea el repositorio `terminal-lab`, su estructura de 16 semanas y lo publica en GitHub. Incluye `hola.sh`, un script que imprime usuario, directorio y fecha.

## Archivos

- `hola.sh` - primer script del curso
- `README.md` - este archivo

## Cómo se ejecuta

```bash
cd semana01
chmod +x hola.sh
./hola.sh
```

## Qué se aprendió

- Los tres estados de Git y el ciclo add / commit / push.
- Cómo publicar un repositorio local en GitHub con `git remote add` y `git push`.
- Escritura y ejecución de un script con shebang y permiso de ejecución.

## Qué quedó pendiente

Nada. Es el capstone de configuración.
